# Valentine Lyric — 我們的歌 ♡

Spotify 風格的雙人播放器，四首歌的專屬播放清單，情人節禮物專用。

|---|---|---|---|

## 功能

- Spotify 風格多曲播放器：左側音樂庫、主歌曲清單、右側「現在播放＋歌詞」、底部播放控制列
- 上一首 / 下一首 / 播放暫停 / 進度條拖曳 / 音量 / 單曲循環
- 每首歌對應歌詞顯示（song1 與 fatgirl_v2 歌詞待補）

## 使用方式

1. 開啟 `index.html`（或 GitHub Pages 連結）
2. 點歌曲開始播放

## 注意

- 圖片使用 Unsplash 遠端資源，需網路連線
- 音檔需與 `index.html` 同目錄
