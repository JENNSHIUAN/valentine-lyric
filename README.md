# Valentine Lyric — 慢慢來比較快 & 淘金小鎮 sing sing 歌

Spotify 風格的單頁播放器 + 歌詞盲猜小遊戲，情人節禮物專用。

## 內容

- **慢慢來比較快** — Wifey 寫給 Hubby 的歌（`song.mp3`）
- **有老公的孩子像個寶 (淘金小鎮 sing sing 歌)** — 挖空歌詞盲猜遊戲

## 使用方式

1. 開啟 `index.html`（或 GitHub Pages 連結）
2. 播歌、點擊 `song.mp3` / `song1.mp3` 播放
3. 遊戲區：聽歌、把挖空的歌詞填完，點「複製整段答案」貼到 LINE 給 Wifey

## 注意

- **`song1.mp3` 尚未加入 repo**（遊戲區那首歌），拿到音檔後放到同資料夾並 `git add song1.mp3 && git push` 即可
- 圖片使用 Unsplash 遠端資源，需網路連線

## 技術

單一 HTML（無框架），原生 JavaScript。
